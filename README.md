# pi-eo-bench

Electro-optical sensor characterization and a real-time C++ image
pipeline, built on a Raspberry Pi 4 with an OV5647 camera module.

## Status

Early development. Current work: inspecting raw sensor data (DNG)
with Python.

## Hardware

- Raspberry Pi 4 Model B (8 GB)
- Arducam OV5647 camera module (5 MP, 10-bit raw Bayer, GBRG)
